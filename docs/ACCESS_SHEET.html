The live .env (the master key file)

The server's ~/crypto-fleet/.env holds every API key and the trading-wallet secret. It is intentionally not in git and cannot be regenerated if lost. To keep a physical backup:

# inside your normal SSH session on the server:
cat ~/crypto-fleet/.env
# ...or as a one-shot from your PC (use your usual SSH target):
ssh fleet 'cat ~/crypto-fleet/.env'

Copy/print the output, then delete any digital copy. Store the printed .env with this Access Sheet, securely. Treat it like the keys to a safe — anyone with it can move money once live trading is on.
